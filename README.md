# Master-Thesis-2026----------------------------------------------------------------------

The zip consists of 12 sub-folders ordered from 01 to 12 containing the main Rcodes and any frozen data, file dependencies and basic replication codes (used when I had to check the codes).  

# Installations
Install the required R packages first. The package setup script and recorded dependencies are in 11_Dependencies/ (Install_Packages.R). Some packages may require compilers when installed from source. The analysis uses frozen data (09), so no financial-data downloads are required.

# Note on codes overall
To avoid too much clutter, the codes were slowly modified throughout the year to now follow this specific structure. Once run, they generate a new folder within each of the 01-12 folder, containing data, figures, models and tables, instead of having everything show up in its raw form in the consoles. 

# Main R scripts
The eight main R scripts are in folders 01–08. Open AI_Energy_Thesis.Rproj in RStudio and run the scripts individually using Source. 
The scripts contain a working-directory line at the top: setwd("/Users/amyhu/Research/AI_Energy_Thesis_Code"). This is the only change that needs to be made to your local location before running the script.

# Rest of the folders
- 09_Shared_Data: frozen data and model inputs needed by the scripts. Keep frozen_models/.
- 10_Shared_Functions: common functions and stock-group definitions.
- 11_Dependencies: R package setup and recorded package requirements.
- 12_Replication_Verification: historical numerical checks and comparisons with earlier code versions. This folder is retained for transparency, but is not part of the usual workflow for generating the main results. Some historical reconciliation entries documented in the paper-to-code mapping are produced here.
